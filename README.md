## 📌 Project Overview
This is a **Java console-based Student Management System** designed for beginners to understand and practice **Java Collections Framework** concepts.

The application stores student details, removes duplicate records, sorts data, performs fast searches, and prints formatted reports.

---

## 🎯 Objectives
- Learn how to use Java Collections
- Understand List, Set, and Map
- Practice sorting with Comparator
- Improve memory usage by avoiding duplicates
- Write clean and readable Java code

---

## 🛠 Technologies Used
- Java (Core Java)
- Java Collections Framework

## 📚 Concepts Implemented

### 1. ArrayList
- Stores student objects in ordered form.

### 2. HashSet
- Removes duplicate students using unique student IDs.
- Helps in memory optimization.

### 3. HashMap
- Provides fast lookup of students using student ID as key.

### 4. Comparator
- Sorts students based on marks in descending order.

### 5. Enhanced For Loop
- Used for easy and readable iteration over collections.

### 6. Collection Hierarchy
Collection
├── List → ArrayList
├── Set → HashSet
└── Map → HashMap

## ▶ How to Run the Project
1. Open the project in any Java IDE (IntelliJ, Eclipse, VS Code).
2. Compile both files:
   - `Student.java`
   - `StudentManagement.java`
3. Run `StudentManagement.java`.
4. View the output in the console.
